# NATURA Aves — miniweb

Web estática, adaptable a móviles, con un test fijo de 10 preguntas para identificar aves.

## Publicarla gratis con GitHub Pages
1. Crea un repositorio en GitHub, por ejemplo `natura-aves`.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets/` a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`. Guarda.
6. GitHub publicará la web en `https://TU-USUARIO.github.io/natura-aves/`.

## Personalización
- El color principal está definido como `--blue` en `style.css` (`#08a9d2`).
- Las diez preguntas, respuestas y enlaces de fotografías están en `script.js`.
- La portada del libro se encuentra en `assets/portada-natura-aves.jpg`.

## Fotografías
Las imágenes se cargan desde Wikimedia Commons mediante sus páginas `Special:FilePath`. La sección “Fotografías y atribuciones” de la web enlaza cada ficha original para consultar autoría y licencia. Las fotografías no se redistribuyen dentro de este repositorio.
